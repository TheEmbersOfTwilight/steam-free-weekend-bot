Steam Free Weekend Bot

A Node.js project that checks Steam for free weekend promotions and sends alerts with Steam store links to a group chat or Discord channel.

How it works

  1. Scrapes Steam specials pages for featured offers.
  2. Stores detected games in a local SQLite database.
  3. Checks for new entries and sends a notification.
  4. Links users directly to the Steam store page.

Quick start

npm install
cp .env.example .env
npm run setup
npm start

Supported platforms

Windows and Linux/macOS are both supported because the bot is built with Node.js and cross-platform scripts.
