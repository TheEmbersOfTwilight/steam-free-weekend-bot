# 🎮 Steam Free Weekend Bot A Node.js bot that monitors Steam for real free weekend listings and posts alerts to a Steam group chat. ## Features ✨ **Actual Steam free weekend detection** - filters out generic Steam specials and only handles weekend titles 📢 **Steam group chat alerts** - sends alerts directly to your Steam group 💾 **SQLite tracking** - stores discovered games and tracks what has already been notified 🔄 **Cross-platform** - works on Windows and Linux/macOS ⚡ **Simple setup** - one setup wizard and `.env` file for credentials ## Prerequisites - Node.js 18+ - npm - Steam bot account with access to the target group - Steam group ID ## Installation ```bash git clone https://github.com/TheEmbersOfTwilight/steam-free-weekend-bot.git cd steam-free-weekend-bot npm install npm run setup npm start ``` ## `env` configuration ```env STEAM_BOT_USERNAME=your_bot_username STEAM_BOT_PASSWORD=your_bot_password TARGET_STEAM_GROUP_ID=your_group_id STEAM_SHARED_SECRET= STEAM_IDENTITY_SECRET= CHECK_INTERVAL_MINUTES=60 DATABASE_PATH=./data/games.db ``` ## Notes This version intentionally filters posted items by actual free weekend text patterns so it avoids false positives from Steam's general sale pages. It is designed to focus on Steam group chat alerts only. ## License MIT
