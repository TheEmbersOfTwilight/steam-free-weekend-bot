🎮 Steam Free Weekend Bot

Automatic Steam free weekend alerts for your group chat

What is it?

A Node.js bot that continuously monitors Steam for free weekend game promotions and automatically posts alerts to your Steam group chat with direct store links. Never miss another free weekend!

✨ Features

Automatic Monitoring

Checks Steam regularly for new free weekend games

Steam Group Integration

Posts alerts directly to your Steam group chat

Smart Tracking

Uses SQLite database to avoid duplicate notifications

Cross-Platform

Works on Windows, Linux, and macOS

Easy Setup

Interactive wizard guides you through configuration

Lightweight

Minimal resource usage - perfect for 24/7 operation

🚀 Quick Start

Get up and running in 5 minutes:

git clone https://github.com/TheEmbersOfTwilight/steam-free-weekend-bot.git
cd steam-free-weekend-bot
npm install
npm run setup
npm start

⚙️ Setup Requirements

  • Node.js (v18 or higher)
  • Steam Bot Account - A dedicated Steam account for the bot
  • Group Permissions - Bot account must have posting rights in your group
  • Steam Group ID - The numeric ID of your target group

📋 How It Works

  1. Scrapes Steam's store pages for free weekend promotions
  2. Stores discovered games in a local SQLite database
  3. Detects new games that haven't been announced yet
  4. Posts announcements with direct Steam store links to your group chat
  5. Tracks notified games to prevent duplicate alerts

💻 Platform Support

Windows: Fully supported. Run directly or as a scheduled task.

Linux/macOS: Fully supported. Can run as a systemd service or cron job.

📚 Configuration

The bot uses a simple .env file for configuration. The setup wizard will help you create one:

STEAM_BOT_USERNAME=your_bot_username
STEAM_BOT_PASSWORD=your_bot_password
TARGET_STEAM_GROUP_ID=your_group_id
CHECK_INTERVAL_MINUTES=60
