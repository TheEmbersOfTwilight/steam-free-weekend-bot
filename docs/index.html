Steam Free Weekend Bot

Automatically detect and announce Steam free weekend games to your group chat

Get Started View on GitHub

✨ Features

🎯 Accurate Detection

Smart pattern matching to identify real free weekend listings, not generic Steam sales.

💬 Group Alerts

Posts notifications directly to your Steam group chat with store links.

📊 Smart Tracking

SQLite database prevents duplicate notifications for the same game.

🖥️ Cross-Platform

Works seamlessly on Windows, Linux, and macOS.

⚙️ Easy Setup

Interactive setup wizard gets you running in minutes.

🚀 Lightweight

Minimal resource usage, perfect for 24/7 operation.

📋 Prerequisites

Required

  • Node.js v18 or higher
  • npm (comes with Node.js)
  • Steam bot account
  • Steam group ID

Optional

  • Steam 2FA credentials
  • Custom check interval
  • Custom database path

🚀 Quick Start

Installation Steps

git clone https://github.com/TheEmbersOfTwilight/steam-free-weekend-bot.git
cd steam-free-weekend-bot
npm install
npm run setup
npm start

💡 Setup Wizard

The interactive setup wizard will guide you through configuring your Steam bot account credentials and target group ID. Just run npm run setup

🔧 How It Works

1️⃣ Scrape

Checks Steam's specials page periodically for free weekend listings.

2️⃣ Filter

Uses pattern matching to identify actual free weekend offers.

3️⃣ Store

Saves discovered games in a local SQLite database.

4️⃣ Detect

Identifies new games that haven't been announced yet.

5️⃣ Announce

Posts free weekend alerts to your Steam group chat.

6️⃣ Track

Marks games as notified to prevent duplicate alerts.

⚙️ Configuration

Environment Variables (.env)

# Steam Bot Credentials (Required)
STEAM_BOT_USERNAME=your_bot_username
STEAM_BOT_PASSWORD=your_bot_password
TARGET_STEAM_GROUP_ID=your_group_id

# Steam 2FA (Optional)
STEAM_SHARED_SECRET=your_shared_secret
STEAM_IDENTITY_SECRET=your_identity_secret

# Bot Settings
CHECK_INTERVAL_MINUTES=60
DATABASE_PATH=./data/games.db

Getting Your Steam Group ID

  1. Open your Steam group in a web browser
  2. Look at the URL: https://steamcommunity.com/gid/[GROUP_ID]/
  3. Copy the numeric GROUP_ID value
  4. Paste it into your configuration

💻 Usage Modes

Start the Bot

npm start

Runs the bot continuously in the background, checking for free weekends at your configured interval.

Development Mode

npm run dev

Auto-reloads when you make code changes. Perfect for testing and development.

Interactive Setup

npm run setup

Launches an interactive wizard to configure your bot credentials and settings.

🐛 Troubleshooting

Bot Won't Start

  • Check Node.js: node --version
  • Install deps: npm install
  • Create .env: npm run setup

Steam Login Fails

  • Verify credentials are correct
  • Check 2FA secrets if enabled
  • Ensure account isn't banned

No Notifications Sent

  • Bot must be in the group
  • Bot needs posting permissions
  • Check console logs for errors
